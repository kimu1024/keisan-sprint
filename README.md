# けいさんスプリント

小学校低学年向けの、スマートフォン・タブレット用計算練習アプリです。

## 主な機能

- 繰り上がりあり／なしの足し算
- 繰り下がりあり／なしの引き算
- 1〜9の段を選べる九九
- 10〜100問の問題数設定
- テンキー回答とストップウォッチ
- 時間のかかった10問の復習
- 「かわいい」「クール」のテーマ切替

## ローカル起動

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

`main` ブランチへのプッシュでGitHub Pagesへ自動公開されます。
