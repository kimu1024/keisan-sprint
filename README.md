# けいさんスプリント

小学校低学年向けの、スマートフォン・タブレット用計算練習アプリです。

## 主な機能

- 複数同時に選べる、繰り上がりあり／なしの足し算
- 複数同時に選べる、繰り下がりあり／なしの引き算
- 複数の段を選べる九九
- 選択範囲の全組み合わせを上限とした、重複なしの出題
- テンキー回答とストップウォッチ
- 誤答後の正解表示と、間違えた問題だけの復習
- 時間のかかった10問の復習
- 「かわいい」「クール」のテーマ切替

## ローカル起動

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

`main` ブランチへのプッシュでGitHub Pagesへ自動公開されます。
