# けいさんスプリント

小学校低学年向けの、スマートフォン・タブレット用計算練習アプリです。

## 主な機能

- 複数同時に選べる、繰り上がりあり／なしの足し算
- 複数同時に選べる、繰り下がりあり／なしの引き算
- 複数の段を選べる九九
- 選択範囲の全組み合わせを上限とした、重複なしの出題
- テンキー回答とストップウォッチ
- 音声モード：答えを発話して「次へ」で即座に進み、元の問題にひも付けて後から判定
- 結果画面に全回答・音声認識テキスト・未確認状態を表示
- 誤答後の正解表示と、間違えた問題だけの復習
- 時間のかかった10問の復習
- 8色のパステルカラーパターン切替

## ローカル起動

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

`main` ブランチへのプッシュでGitHub Pagesへ自動公開されます。

## 音声入力

設定画面で音声入力をONにし、マイクを許可します。本番の問題で使用でき、復習はテンキーで行います。数字を入力した場合はテンキー回答を優先します。タイムは「次へ」を押した時点で確定し、認識待ちを加算しません。全件の判定後に復習ボタンを有効化します。

Web Speech API対応ブラウザと通信環境が必要です。音声がブラウザ提供元の認識サービスへ送信される場合があります。アプリ独自の録音保存や認識サーバーはありません。「次へ」でその問題のマイクを停止し、確定結果は問題別のキューで受け取ります。次問はすぐ表示され、ブラウザが前問のマイクを解放すると次問用の聞き取りを始めます。「マイク切替中」では問題を考えたりテンキーを使ったりできますが、音声回答は「聞き取り中」に変わってから話してください。複数の数字を認識した場合は最後の数字で判定します（例：` / 12 / 16` → `16`）。認識テキストは全文を結果一覧に残します。空音声・認識失敗は未確認として復習対象に含め、認識終了が返らない場合は8秒で打ち切ります。

非同期の問題対応と数値変換の検証：`node --test app/voice.test.mjs`（Node 24）。実機のマイク精度・権限・再開挙動は対象端末での確認が必要です。
